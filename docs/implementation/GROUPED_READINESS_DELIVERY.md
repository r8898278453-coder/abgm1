## Review-only release package

Build runs the same migration-source/Vite/server/worker stages through a wrapper that captures source identity before and after all stages. dist/build-provenance.json binds exact artifact bytes to the committed source boundary; dirty or moved-source builds cannot be prepared as a clean release.

`npm run release:prepare -- --base <review-reference> --out <new-directory-outside-repository>` creates exact dependency manifests and client/server/worker artifact copies, SHA-256/size inventory, build proof, capability manifest, source-review.patch and the runbook. It rejects source changes, artifact tampering, stale capability documents, symlinked/oversize artifacts, unsafe references, output inside the repository and existing output directories. Environment files, uploads, SQL exports and node_modules are excluded. Comparison reference is explicitly not the deployed baseline. The manifest always records executionAllowed=false, unknown actual deployed revision and required hosting/backup/previous-artifact/provider/approval evidence. No deploy, SQL migration, provider send or rollback is executed.

Rollback instructions require a tested previous artifact/database compatibility and verified host commands; no guessed shared-host process commands or destructive import are invented. Package preparation is complete review work; actual release remains blocked by unfinished prerequisites and separate authorization.
