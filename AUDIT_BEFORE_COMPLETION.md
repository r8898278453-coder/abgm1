## 3. Immediate P0 Action Plan

1. **Purge Seed Data:** Eliminate `comp_aaditech_main`, `biz_aaditech`, `lead_1`, `lead_2`, `defaultSeedReviews`, `defaultSeedPosts`, and auto-seeding blocks in `schema.sql` and `server/db.ts`.
2. **Fail-Closed DB:** When running in production mode, MySQL connection failures must fail closed (HTTP 503) instead of silently mutating in-memory fallback stores.
3. **Public Form Token & Tenant Isolation:** Add `public_form_token` to `companies` and require it on public lead ingestion. Remove `getDefaultCompanyId()` fallback on tenant endpoints.
4. **Local SEO Anti-Fabrication:** Eliminate `rating || 4.5`, `reviewsCount || 15`, `|| 20`, and fallback to Thane/Mumbai in `resolveCenterCoordinates`.
5. **Growth Score Query Correction:** Remove hardcoded `'default'` keyword observation query; aggregate across real tracked keywords.
6. **Audit Engine API:** Add `POST /api/companies/:id/audit/scan` and `POST /api/companies/:id/audit/fix` endpoints; remove unbacked statistical claims.
7. **Durable Emergency Stop:** Persist global kill switch state so that it survives server restarts.
8. **Frontend Data Truth:** Clean up `src/App.tsx` and views so new workspaces start with an honest empty baseline instead of pre-populating with mock data.
9. **Test Suite Expansion:** Add test coverage for all fixed gap areas.
